# Aurora — VPN-клиент для iOS на Xray-core

Аналог Happ и INCY: одно ядро Xray-core (26.x) прямо в VPN-расширении iOS, без tun2socks — у Xray есть собственный TUN для iOS.

## Возможности

**Протоколы:** VLESS (Reality, XTLS Vision, XHTTP, WS, gRPC, HTTPUpgrade, mKCP), VMess (обе формы ссылок, в том числе base64 из v2rayN), Trojan, Shadowsocks (включая 2022), SOCKS, Hysteria2 (с обфускацией salamander и pinSHA256), WireGuard, полные JSON-конфиги Xray.

**Подписки:** base64, списки ссылок, JSON-массивы конфигов; Age-шифрованные подписки; заголовки `profile-title`, `subscription-userinfo` (трафик и срок), `profile-update-interval`, `support-url`, `profile-web-page-url`, `announce`, `routing`; те же поля строками `#key: value` в теле. HWID (`x-hwid`, `x-device-os`, `x-ver-os`, `x-device-model`) для панелей с лимитом устройств, выбор User-Agent, автообновление в фоне, слияние без потери выбранного сервера.

**Импорт:** буфер обмена, QR (камера и фото), диплинки `aurora://`, `happ://add/…`, `happ://routing/add|onadd/…`, `v2raytun://import/…`, `sing-box://import-remote-profile?url=…`, прямые ссылки `vless://` и т. п., файлы резервной копии.

**Маршрутизация:** режимы «Правила», «Глобально», «Напрямую»; профили, совместимые с форматом Happ (импорт и экспорт); российские сайты напрямую (работает и без geo-баз); блокировка рекламы; блокировка QUIC; свои списки доменов и IP (direct/proxy/block); hosts; удалённый и прямой DNS, FakeDNS; geoip/geosite с автозагрузкой.

**Подключение:** Kill Switch (includeAllNetworks), исключение локальной сети, APNs и сервисов оператора; автоподключение (On Demand) по Wi-Fi/сотовой и доверенные SSID; переподключение при смене сети и после сна; IPv6; MTU; лимит памяти ядра.

**Чего нет в Happ/INCY или сделано лучше:**
- «Авто: лучший сервер» — до 12 серверов в балансировщике Xray (leastPing + observatory): ядро само переключается на быстрейший без разрыва туннеля;
- цепочка прокси (входной узел → сервер);
- фрагментация TLS ClientHello и Mux;
- реальная задержка (URL-тест через само ядро) и TCP-пинг, «подключить лучший», «удалить недоступные»;
- проверка конфига ядром до подключения и живая проверка JSON при редактировании;
- предпросмотр итогового конфига Xray;
- локальный SOCKS5/HTTP-прокси с раздачей в локальную сеть;
- работа без App Group (если подпись её срезала): конфиг передаётся через настройки VPN, статистика и журнал — через сообщения расширению;
- Siri и Быстрые команды: включить, выключить, переключить, статус;
- статистика по дням, скорость в реальном времени с графиком, резервные копии.

**Уведомления iOS (отдельный экран «Настройки → Уведомления»):** статус разрешения и переход в настройки iOS; звук, значок, скрытие имени сервера; важность (тихо / обычно / важно — time-sensitive); подключение, отключение, обрыв, переподключение, смена сети, смена сервера; конец подписки за N дней (запланированные заранее, приходят даже при закрытом приложении), остаток трафика (порог в %), обновление и ошибки подписки, объявления провайдера; итоги сессии, ежедневная сводка, лимит трафика за сессию; тихие часы, сквозь которые проходят только важные. Уведомления приходят и из VPN-расширения, когда приложение закрыто.

## Сборка

GitHub Actions (`.github/workflows/aurora.yml`) на macOS:
1. `gomobile bind` собирает `Corebridge.xcframework` из `Aurora/Core` (Xray-core + мост; кэшируется);
2. XcodeGen генерирует проект, `xcodebuild` собирает без подписи;
3. приложение и расширение подписываются ad-hoc с entitlements и упаковываются в `Aurora.ipa` (артефакт `Aurora-ipa`).

Ядро и сборку конфигов можно проверить без Mac: `cd Aurora/Core && go test ./...`.

## Установка — важно

VPN на iOS работает только через Network Extension, и подпись должна сохранить entitlement `com.apple.developer.networking.networkextension` (`packet-tunnel-provider`) у приложения и у `PlugIns/Tunnel.appex`:

- **TrollStore** — ставится как есть, entitlements берутся из IPA;
- **платный аккаунт разработчика / сертификат** (Sideloadly, ESign, Feather, Scarlet и т. п.) — профиль должен включать возможность Network Extensions (wildcard-профили её не дают);
- **бесплатный Apple ID** — Apple не выдаёт Network Extension для бесплатных аккаунтов: приложение установится, но VPN не включится.

App Group (`group.com.werx.aurora`) необязательна: без неё всё работает, geo-базы расширение скачивает само.
